# AI Study Assistant Prototype

A polished React + Vite frontend prototype for a B.Tech Generative AI project: a Retrieval-Augmented Generation (RAG) PDF chatbot for engineering students.

## Built With

- React.js
- Vite
- Tailwind CSS
- React Router
- Lucide React icons

## Pages Included

- Landing Page
- Dashboard
- Upload PDF Page
- AI Chat Page
- Documents Page
- About Page

## Features

- Responsive blue-and-white academic UI
- Sidebar navigation
- Mock data for PDF uploads, chat, documents, and workflow
- Reusable React components
- Clean folder structure, ready for backend integration

## Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

## Project Structure

- `src/components/` — reusable UI components
- `src/pages/` — page views and layouts
- `src/data/mockData.js` — mock content for prototype screens
- `src/App.jsx` — router and layout
- `src/index.css` — Tailwind setup and global styles

## Notes

This is a frontend-only prototype with mock data. The UI is designed to be extended into a complete RAG application later.
